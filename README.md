# BIOS15_Report-2
Repository for BIOS15 report 2

All analysis is provided in `scripts/Analysis.R`. You can run the whole thing in one go or go line by line.

The report can be found in plain `.tex` format at `report/main.tex` and as a `.pdf` at `report/Todreas_BIOS15_Report-2`.

Directory structure:
```markdown
root/
├── data/
│   └── Eulaema.csv 
├── outputs/

│   ├── fig1.pdf
│   └── summary.txt
├── report/
│   ├── fig1.pdf
│   ├── main.tex
│   └── Todreas_BIOS15_Report-2.pdf
├── scripts/
│   └── Analysis.R
├── .gitignore
├── BIOS15_Report-2.Rproj
└── README.md
```
